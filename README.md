# ポートフォリオサイト

作品のフォルダを `works/` に入れるだけで、サイトが自動で組み上がります。
インストールは不要です(Mac 標準の Python だけで動きます)。

## 更新のしかた

### 方法1: ウィザードで追加(おすすめ)

1. `作品を追加.command` をダブルクリック
2. 聞かれることに答える(URLを貼る → タイトル → 表紙画像をドラッグ&ドロップ)
   - YouTube / Spotify のURLなら、タイトルと表紙は自動で取得されます
3. 最後に「サイトを更新しますか?」で Enter

### 方法2: フォルダを手で作る

`works/` の中に新しいフォルダを作り、`info.txt` と画像を入れます。

```
works/2026-10-01-新曲/
  info.txt      ← 必須
  cover.jpg     ← 表紙(なければ最初の画像、YouTubeならサムネイル、それもなければ自動の色面)
  photo1.jpg    ← 他の画像は作品ページのギャラリーになる
```

`info.txt` の書き方(`title` 以外は全部省略可):

```
title: 新曲タイトル
date: 2026-10-01
type: 音楽              ← 音楽 / 動画 / グッズ / その他。省略するとリンク先から自動判定
description: 一言説明
links:
https://open.spotify.com/track/...       ← URLだけでOK。ボタン名は自動
BOOTH: https://example.booth.pm/items/1  ← 名前を付けたいときは「名前: URL」
---
ここから下は自由なメモ(制作の裏話など)
```

- 下書きにしたいとき: `draft: yes` と書く、またはフォルダ名の頭に `_` を付ける
- 作品を消す: フォルダごと削除
- 並び順は日付の新しい順。日付を省略するとフォルダ名の頭(2026-10-01-…)から読みます

### 自動で埋め込みプレーヤーになるリンク

YouTube / Spotify / Apple Music / SoundCloud / ニコニコ動画。
それ以外(BOOTH・Amazon・Bandcamp など)はボタンになります。

## サイトを作り直す

`サイトを更新.command` をダブルクリック。`docs/` フォルダが作り直されます。
(ターミナルなら `python3 build.py`)

## サイト全体の設定

`site.txt` に次のことを書きます。最初に一度だけでOKです。

- `name` / `tagline` / 自己紹介(`---` の下)
- `menu:` … 左のメニューに「Works」「About」に続いて並ぶ項目(通販ページなど)
- `links:` … メニューの下に小さく並ぶSNSなどのリンク
- `contact:` … メニューの末尾に出る「Contact」の行き先(メールアドレスかURL。空なら項目なし)
- `logo:` … ロゴ画像のファイル名(このフォルダに置く)。空なら名前を文字で表示
- `background:` … トップページの背景動画。空なら Works に入れたYouTube動画をシャッフルして流す。URLなら1本に固定、`off` で無し
- `mosaic:` … 背景動画のモザイク(タイル)の大きさ。大きいほど粗い。0でモザイクなし

見た目を変えたいときは `theme/style.css`。先頭の `:root` の色(`--main` がボタンやバッジの青)を変えれば全体が変わります。

## トップページと Works

トップは、左に名前とメニュー、右に Works の文字リスト(日付・タイトル・種類)を置き、背景に動画が流れます。
リストの行にカーソルを乗せると、その作品のジャケットがリストの右隣に出ます(スマホでは出ません)。種類での絞り込みボタンつき。
リストの見た目は `style.css` の `.works-list` / `.row`、ジャケットの表示は `.peek` と `fx.js` です。

## 演出について

動きの部分は `theme/fx.js`(動作)と `theme/style.css`(見た目)にあります。

- **紙のようなざらつき**: 全体に薄いノイズを重ねています。濃さは `style.css` の `body::after` の `opacity`(0で無し)。
- **フェードイン / ページ遷移**: 開くと順にふわっと現れ、リンクを押すと暗転してから移動します。
- **効果音**: 右下の「♪ OFF」を押すと ON になり、ホバーやクリックで小さな音が鳴ります。初期は無音で、選択はブラウザに記憶されます。音源ファイルは使わずコードで合成しています。
- **マウス追従**: カーソルを追う丸と、ジャケットが傾く動き。背景動画があるときは、丸が「レンズ」になります(下の背景動画を参照)。
- **背景動画**: トップページの背景で、Works に入れた YouTube の動画が(開くたびに順番をシャッフルして、1本ずつ)流れ、終わると次の動画に切り替わります。初期は無音で、右下の「♪」を ON にすると動画の音が小さく流れます(音量は `fx.js` の `VIDEO_VOLUME`)。タイルの格子と背景色のかぶせで、文字が読めるようにしています。かぶせの濃さは `style.css` の `.bgvideo` の `--dim`(小さいほど動画がはっきり見える)。
  - **文字色の自動調整**: 背景動画が表示されている間、メニューとリストの文字は「背景が明るい所は暗く、暗い所は明るく」自動で変わります(CSS の `mix-blend-mode: difference`)。YouTube の映像は外部のものなのでピクセルを読み取れず、色の反転で近似しています。背景が中間の明るさ(灰色)のところでは読みにくくなることがあります。やめたいときは `style.css` の「文字色を背景に合わせて変える」ブロックを消してください。
  - **レンズ**: カーソルの周りだけモザイクとかぶせが消えて、映像がクリアに見えます。メニュー・Works のリストなど文字そのものの上ではレンズが閉じ(文字の横の余白では開き)、読みやすさを保ちます。大きさは `fx.js` の `LENS_R`、閉じる場所は `READING` で変えられます。

スマホなどマウスのない端末と、OSで「視差効果を減らす」を設定している環境では、遷移のフェード・マウス追従・背景動画は自動で無効になります(通信量の節約にもなります)。
演出が不要なら、`build.py` の `fx.js` を読み込む行を消せばOKです。

背景に使う動画は、埋め込みが許可されているもの(自分で公開した動画など)にしてください。

## 公開のしくみ(GitHub Pages + 自動ビルド)

`works/` や `site.txt` を変えて GitHub に push すると、GitHub 側が自動でサイトを作り直して公開します(`.github/workflows/pages.yml`)。
`docs/` は自分のMacでの確認用で、GitHub には載せません(`.gitignore` で除外)。

- いつもの更新: `作品を追加.command` で作品を足し、`サイトを更新.command` をダブルクリック(確認用ビルド → push)。反映まで1〜2分。
- Macがなくても、GitHub のサイト上で `works/` にフォルダやファイルをアップロードすれば、同じように公開されます。
- うまく公開されないときは、GitHub のリポジトリの「Actions」タブでエラーを確認できます。

注意:
- 作品の日付は、`info.txt` の `date:` か、フォルダ名の頭(`2026-10-01-…`)で必ず指定してください(`作品を追加.command` で作ったものは自動で入ります)。
- 写真は jpg / png / webp / gif / svg。iPhone の HEIC 形式は表示できないので、jpg に変換してください。
- `works/` と `site.txt` の中身は、そのまま公開されます(リポジトリが公開のため)。メールアドレスなど、載せたくない情報は書かないでください。
